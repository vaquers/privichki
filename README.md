# Habit Tracker Bot

Персональный Telegram-бот для отслеживания ежедневных привычек.

## Установка

```bash
cd habit_bot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Настройка

Скопируй `.env.example` в `.env` и заполни:

```bash
cp .env.example .env
```

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `ALLOWED_USER_ID` | Твой Telegram user ID (узнать: @userinfobot) |
| `DAILY_TIME` | Время утренней карточки (HH:MM) |
| `EVENING_TIME` | Напоминание о незакрытом, по умолчанию `21:00` |
| `WEEK_SUMMARY_TIME` | Итог недели по воскресеньям, по умолчанию `21:30` |
| `TIMEZONE` | Часовой пояс (например `Europe/Minsk`) |
| `DATABASE_URL` | Строка подключения к PostgreSQL |

## Запуск

```bash
python main.py
```

## Кнопки

- **Сегодня** — карточка дня с пунктами, назначенными на этот день недели
- **Статистика** — проценты, серии и разбивка по дням недели
- **Манул** — таблица клиентов с редактированием как в таблице
- **Экономика** — конспекты по пройденным темам
- **Календарь** — сетка месяца: зелёный день закрыт полностью, красный пропущен,
  синий — сегодня. Нажатие открывает карточку того дня

## Задачи дня

Под карточкой есть «Добавить задачу»: разовые дела конкретного дня, не привычки.
Задача появляется отдельной кнопкой и зеленеет при нажатии — привычки синеют,
поэтому одно от другого отличается на глаз. Задачи привязаны к дате и в
статистику привычек не идут, но учитываются в цвете дня в календаре.

Открытие прошлого дня из календаря не создаёт для него строк в `daily_log`:
иначе давно прошедший день задним числом превратился бы в набор невыполненных
пунктов и испортил проценты. Отметка на таком дне по-прежнему сохраняется.

## Расписание

Каждая привычка хранит в поле `schedule` карту «день недели → подпись».
День, которого нет в карте, — привычка в этот день не показывается.

| Пункт | Подпись | Дни |
|---|---|---|
| Математика | `репет` / `1/3 дз` | Пн, Вт, Чт, Сб |
| Сайты | `1 сайт` | каждый день |
| Спорт | `тренировка` | каждый день |
| Экономика | `пол темы` | каждый день |
| Душ | `холодный` | каждый день |
| Сон | `8 часов` | каждый день |

Расписание засевается один раз и потом не перезаписывается при рестарте,
так что правки в базе сохраняются.

## Как считается статистика

Строки в `daily_log` заводятся только на запланированные пункты, поэтому сами
строки и есть «что ожидалось в этот день». Проценты делятся на них, а не на
календарные дни: математика на четырёх днях в неделю показывает свои 100 %, а не
13 %. Дни, отмеченные кнопкой «Пропустить день», из расчёта выпадают.

## Таблица клиентов

Колонки: Компания, Текст сообщения, Текст ответа, Видео сайта, Комментарий.

У «Текст ответа» есть кнопка «⏳ жду» — заполняет ячейку без ввода, пока ответа
нет. Когда ответ придёт, ячейка правится обычным способом.

«Видео сайта» хранит Telegram file_id: видео присылается боту и остаётся лежать
на серверах Telegram, у нас ни хранилища, ни лимита по размеру. В таблице такая
ячейка показывает `🎥 есть`, сам идентификатор наружу не выводится. Посмотреть
видео — кнопка «▶️» в карточке компании.

Колонки, удалённые при переходе на эту схему, не пропали: их значения лежат в
`client_values_archive` вместе с именем колонки и датой.

## Экономика

Две отметки «пол темы» = пройденная тема. После второй бот сам предлагает
записать конспект. Раздел хранит название, текст, дату и порядковый номер темы.

## Картинки

Карточки привычек лежат в `assets/cards/`. У душа и сна картинок пока нет —
они рисуются цветной плашкой. Добавь файлы и пропиши их в `HABIT_STYLE`
в `render.py`, чтобы заменить плашку.
